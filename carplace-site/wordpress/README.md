# Подключение отправки в WordPress

1. Скопируйте папку `wordpress` как `wp-content/plugins/detailing-leads` и активируйте **Detailing Leads** в админке WordPress.
2. Откройте **Настройки → Заявки детейлинга**, укажите email владельца. Если поле пустое, используется административный email WordPress. Адрес получателя задаётся только на сервере.
3. Перенесите HTML в тему, сохранив `site-data.js`, `lead-form.js`, `lead-form.css` и `script.js`. В теме вызовите `wp_head()` перед `</head>`: плагин подставит правильный REST URL, в том числе при WordPress в подпапке. При ручной интеграции укажите этот адрес в `SITE_DATA.form.endpoint`.
4. Настройте почту хостинга / SMTP и отправьте контрольную заявку на свой ящик. Проверьте само письмо и папку «Спам», затем контактный телефон, выбранную услугу и филиал в письме.

На GitHub Pages и при открытии HTML с диска нет PHP/WordPress. Форма делает настоящий HTTP POST, но без установленного обработчика покажет ошибку; ложного «отправлено» нет. Для теста нужен WordPress на том же домене. Адрес endpoint по умолчанию: `/wp-json/detailing/v1/leads`.

Форма запрашивает телефон, автомобиль и согласие на обратную связь. Имя и описание необязательны. Фотографии можно передать позже в мессенджере. Если для запуска нужна отдельная политика обработки данных, добавьте ссылку в текст согласия.

Обработчик проверяет поля и Origin, ограничивает размер запроса, отсекает honeypot и более пяти попыток за 10 минут с одного IP. Успешно отправленные номера запросов запоминаются на час, чтобы повтор после потери ответа не отправлял письмо второй раз. IP хранится только как HMAC в ключе временного ограничения; персональные данные в базе плагин не сохраняет. При высокой нагрузке защиту от автоматических запросов можно усилить на хостинге.

Успех `wp_mail()` подтверждает передачу почтовой системе, а не доставку в ящик. Документация: [wp_mail](https://developer.wordpress.org/reference/functions/wp_mail/), [REST endpoints](https://developer.wordpress.org/rest-api/extending-the-rest-api/adding-custom-endpoints/).
