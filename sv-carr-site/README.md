# Sv_carr

Независимый сайт на HTML/CSS/JS. Откройте index.html в браузере. Установка пакетов и сборка не нужны.

Видимые тексты и метаданные — index.html; оформление — styles.css; контакты и параметры формы — site-data.js; поведение — script.js; изображения — assets/images/. У каждого сайта собственные файлы, общих зависимостей с другими студиями нет.

Для GitHub Pages загрузите содержимое этой папки в корень отдельного репозитория. Settings → Pages → Deploy from a branch → main → /(root). .nojekyll уже добавлен.

Форма отправляет JSON-заявку через обработчик WordPress. Для приёма установите плагин из wordpress/ и задайте email в админке. На GitHub Pages серверного обработчика нет; форма покажет ошибку, сохранив введённые данные. Подключение — wordpress/README.md. Источники и оговорки — SOURCES.md.
